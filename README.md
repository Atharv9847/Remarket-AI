ReMarket AI
ReMarket AI is a modern second-hand marketplace that helps users buy, sell, exchange, and negotiate pre-owned products with confidence. The platform combines AI-powered price valuation, condition analysis, verified seller profiles, favorites, offers, real-time chat, and secure transaction workflows.

Users can browse products by category, search listings, filter by condition and price, create listings, make offers, negotiate with sellers, exchange items, and communicate through the built-in messaging system.

Main Features
AI-powered fair market price estimation
Product condition analysis
Second-hand product listings
Search, categories, sorting, and filters
User authentication and seller profiles
Favorites and saved products
Buy, sell, barter, and exchange workflows
Offers and counter-offers
Real-time buyer-seller chat
Seller trust indicators and reviews
FastAPI backend with SQLite/PostgreSQL support
React and Vite frontend
REST API documentation with Swagger UI
